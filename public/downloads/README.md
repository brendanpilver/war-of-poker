# Public downloads

Free assets served directly at `/downloads/<file>`. Anything **paid** belongs in
the private Supabase Storage `products` bucket instead — see
[`docs/GROWTH-ARCHITECTURE.md`](../../docs/GROWTH-ARCHITECTURE.md).

## Required

| File | Used by |
| ---- | ------- |
| `nlh-to-plo-survival-card.pdf` | The welcome email sent by `/api/subscribe` |

It is the Microsoft Word export of `FREE_NLH_PLO_Survival_Card_FINAL.docx` in
the publication set (`publication_final/pdf/FREE_NLH_PLO_Survival_Card_FINAL.pdf`),
copied here byte for byte. When the card is revised, replace this copy with the
new export under the same filename.
