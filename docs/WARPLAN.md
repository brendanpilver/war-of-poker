**WARPLAN is the proprietary poker decision-making system inside the War of Poker
universe.** WARPLAN is *not* the name of the brand. The brand and world is
**War of Poker**. See [`BRAND.md`](./BRAND.md) for that distinction.

WARPLAN is a thinking framework. The wider War of Poker world may be playful;
WARPLAN itself must stay a credible poker-thinking framework.

---

## The WARPLAN Steps

WARPLAN is an acronym. Each letter is one step of the decision process.

| Letter | Step | Sub-structure |
| ------ | ---- | ------------- |
| **W** | WHO? — Profile the Player | Rank + Style + Situation |
| **A** | ACTION SO FAR — SCALE the Action | Setup • Chronology • Amounts • Live Cues • Exceptions |
| **R** | RANGES LIKELY — Bracket • Weight • Compare | Buckets, Weights, Comparison |
| **P** | POSSIBLE RESPONSES — Consider All the Options | Action → Size → Response |
| **L** | LONG-RANGE IMPLICATIONS — FIRE Ahead | Future Cards • Investment • Responses • Effects |
| **A** | AIM & ACTION — Finish on TOP | Target • Outcome • Play |
| **N** | NOTHING ELSE | Final pause / check step |

## Rules for Agents and Contributors

1. WARPLAN terminology is fixed. Never rename, re-abbreviate, translate, or
   "clarify" a canonical term.
2. Never add a bucket, weight, action, size, or step.
3. Never reorder the steps or the items inside a step.

   from general poker theory and write it in as doctrine.

   Do not resolve it by editing this document.
